# Бокс — ShortGames

Маленький файтинг на three.js: 2 боксёра, ринг, 4 удара, уклоны, нырок, блок. Один HTML-файл, без сборки.

**Играть:** https://zeghreit.github.io/boxing/ (на iPhone: Safari → «Поделиться» → «На экран Домой» — будет полноэкранно).

## Управление

| Действие | Телефон | Клавиатура |
|---|---|---|
| Ходьба / круг вокруг соперника | джойстик слева | WASD / стрелки |
| Джеб / Кросс (прямые) | ДЖЕБ / КРОСС | J / K |
| Хук / Апперкот | ХУК / АППЕР | U / I |
| Блок (держать) | БЛОК | Пробел / Shift |
| Уклон влево / вправо | ◀ / ▶ | Q / E |
| Нырок | ▼ | C |
| Пауза | ❚❚ | P / Esc |

## Правила
- Уклон в сторону уходит от прямых и апперкотов, но не от хука.
- Нырок уходит от прямых и хуков, но апперкот по нырку — ×1.4.
- Удар сразу после удачного уклона — контра ×1.5; удар в замах соперника — встречный ×1.3.
- Блок режет урон до 20%, но тратит выносливость; пустая выносливость = блок пробит.
- 3 раунда по 60 с. Нокдаун — счёт до 10 (свой — вставай, жми удары). 3 нокдауна = ТКО. Иначе по очкам.
